Pipeline Pipeline Stack

  • Ingestion: PyMuPDF (fitz) for searchable PDFs + pdf2image with Poppler for scanned docs.
  • OCR Engine: Tesseract OCR with multi-language Indic packs (`kan+eng`, `san`, `hin`, `tam`, `tel`).
  • Normalization: Indic Virama U+0CCD restoration, double consonant collapse, and short/long vowel repairs.
  • Morphology: Agglutinative Kannada suffix stripping, stem analysis, and Sandhi joining.
  • Scoring: Weighted Levenshtein distance with Indic confusion pairs + N-gram context ranking.
  • Export: FPDF2 layout-preserved PDF with Noto Sans Kannada Unicode TTF + JSON metadata.
